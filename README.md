## GitHub Copilot في VS Code
### أنماط الاستخدام المتاحة حاليًا
**ملاحظة:** GitHub Copilot في VS Code يعمل سحابيًا حاليًا ولا يوفّر تشغيل النماذج محليًا.
- **Cloud (سحابي):** المعالجة تتم عبر خدمات GitHub Copilot السحابية، وتحتاج اتصالًا بالشبكة.
- **Copilot Chat:** وضع الدردشة في Copilot لطرح الأسئلة وفهم الكود أو الحصول على شرح سريع قبل التغيير.

### الفروق الرئيسية
- **الخصوصية:** تعتمد على سياسات GitHub Copilot ومعايير المؤسسة.
- **الجودة:** تعتمد على قدرات النموذج السحابي المستخدم.
- **سرعة الاستجابة:** تتأثر بجودة الاتصال بالشبكة.
- **متطلبات الاتصال:** يلزم اتصال بالإنترنت لاستخدام Copilot.

### إرشادات اختيار الاستخدام المناسب
- **عمل حساس أو قيود بيانات صارمة:** راجع سياسات المؤسسة وضوابط GitHub Copilot قبل التمكين.
- **إنترنت محدود أو متذبذب:** Copilot قد لا يكون مناسبًا لغياب وضع محلي.
- **جودة أعلى أو مخرجات أكثر تعمقًا:** حافظ على اتصال مستقر.
- **أسئلة سريعة لفهم الكود قبل التعديل:** استخدم Copilot Chat.

### أين تغيّر الإعدادات في VS Code
افتح **Settings** (Ctrl+,) ثم ابحث عن **GitHub Copilot** لتفعيل/تعطيل الاقتراحات وتكوين ميزات الدردشة. وللوصول السريع، استخدم **Command Palette** (Ctrl+Shift+P) وابحث عن **Copilot** للوصول إلى أوامر الامتداد المتاحة.
