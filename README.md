## GitHub Copilot في VS Code
**سؤال توضيحي:** هل تريد الشرح داخل VS Code فقط أم مقارنة مع أدوات أخرى؟ تحديد النطاق يساعد على دقة الإجابة.

### الأوضاع (Local / Cloud / Ask) ومتى تُستخدم
- **Local (محلي):** يعتمد على تشغيل النموذج محليًا عندما يكون ذلك متاحًا. مناسب للبيئات الحساسة للبيانات أو عند تفضيل بقاء المعالجة على الجهاز.
- **Cloud (سحابي):** يعتمد على معالجة سحابية. مناسب عندما تريد جودة أعلى أو إجابات أعمق وتتوفر لديك شبكة مستقرة.
- **Ask (Copilot Chat):** وضع الدردشة في Copilot لطرح الأسئلة وفهم الكود أو الحصول على شرح سريع قبل التغيير.

### الفروق الرئيسية
- **الخصوصية:** المحلي عادةً أعلى خصوصية، والسحابي يعتمد على سياسات الخدمة.
- **الجودة:** السحابي غالبًا يقدم جودة أفضل بسبب قدرات النموذج.
- **سرعة الاستجابة:** المحلي يعتمد على عتاد الجهاز، والسحابي يعتمد على سرعة الاتصال.
- **متطلبات الاتصال:** المحلي أقل اعتمادًا على الإنترنت، والسحابي يحتاج اتصالًا مستقرًا.

### إرشادات اختيار الوضع المناسب
- **عمل حساس أو قيود بيانات صارمة:** اختر Local إن كان متاحًا.
- **إنترنت محدود أو متذبذب:** Local أفضل لتقليل الاعتماد على الشبكة.
- **جودة أعلى أو مخرجات أكثر تعمقًا:** Cloud مناسب غالبًا.
- **أسئلة سريعة لفهم الكود قبل التعديل:** استخدم Ask.

### أين تغيّر الإعدادات في VS Code
افتح **Settings** (Ctrl+,) ثم ابحث عن **Copilot**. من إعدادات امتداد **GitHub Copilot** ستجد خيارات النماذج/الأوضاع المتاحة، ويمكنك تعديلها أيضًا عبر لوحة Copilot أو أيقونة Copilot في شريط الحالة إن كانت مفعّلة.
